# data/

The guide reads these at runtime:

- `trylist.xlsx` — shared To-try list
- `tabung.xlsx` — shared Tabung (money pool) ledger

Both are configured in `../index.html` via `SHARED_SHEET_IDS` and the Apps Script
endpoint. Drop the exported .xlsx files here if you want the guide to work offline
from the folder as well as from the sheets.
